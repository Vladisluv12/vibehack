Новая заметка

Новая запись появится со статусом «Предложено». Для связи используйте [[название заметки]], тег можно поставить и прямо в тексте: #идея.

GitHub-репозиторий

Markdown-файлы репозитория (README, docs и другие) появятся как источники со статусом «Не проверено» и соберутся в кластер вокруг проекта репозитория. Нужна сеть; код и бинарные файлы не скачиваются на диск. Для приватных репозиториев запустите сервер с переменной окружения GITHUB_TOKEN.

Настройки

Эмбеддинги

Заметки режутся на фрагменты, вектор каждого фрагмента запрашивается у выбранного эндпоинта и хранится локально в индексе. Повторно запрашиваются только изменившиеся фрагменты.

Для русского и английского хорошо работают bge-m3 и USER-bge-m3 (без префикса). Для multilingual-e5 укажите префикс «query: ».
